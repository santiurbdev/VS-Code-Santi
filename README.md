## 🇬🇧 English Version

### 📌 Overview
**System Academy** is a modular Python solution designed to simulate a complete academic administration ecosystem. Built entirely around **Object-Oriented Programming (OOP)** principles, the system demonstrates clean architecture, data encapsulation, and scalable class hierarchies for managing core institutional operations.

### 🏗️ Architecture & Modules

| Module | Scope & Responsibility | Key OOP Concepts |
| :--- | :--- | :--- |
| **`01_cursos`** | Course creation, enrollment capacity, and curriculum management. | Encapsulation, Methods |
| **`02_estudiantes`** | Student profile lifecycle, track enrollment, and status checks. | Inheritance, Attributes |
| **`03_evaluaciones`** | Grade calculation, exam weighting, and performance metrics. | Polymorphism, Overriding |
| **`04_docentes`** | Faculty assignment, teaching hours, and course allocation. | Abstract Base Classes (ABC) |

### 🛠️ Technical Highlights
* **Abstract Base Classes (`abc` module):** Enforces strict interface blueprints across entity types.
* **Polymorphic Methods:** Standardized calculation behavior across different evaluation formats.
* **Robust Encapsulation:** Private attributes with controlled access via getters and setters.

## 🇪🇸 Versión en Español

### 📌 Descripción General
**System Academy** es una solución modular en Python diseñada para simular un ecosistema completo de administración académica. Desarrollado bajo los principios de la **Programación Orientada a Objetos (POO)**, el sistema demuestra una arquitectura limpia, encapsulamiento de datos y jerarquías de clases escalables para gestionar operaciones institucionales clave.

### 🏗️ Arquitectura y Módulos

| Módulo | Alcance y Responsabilidad | Conceptos Clave de POO |
| :--- | :--- | :--- |
| **`01_cursos`** | Creación de cursos, capacidad de cupos y gestión de planes de estudio. | Encapsulamiento, Métodos |
| **`02_estudiantes`** | Ciclo de vida del estudiante, matrícula de asignaturas y estado. | Herencia, Atributos |
| **`03_evaluaciones`** | Cálculo de notas, ponderación de exámenes y métricas académicas. | Polimorfismo, Sobreescritura |
| **`04_docentes`** | Asignación docente, carga horaria y vinculación de asignaturas. | Clases Abstractas (ABC) |

### 🛠️ Aspectos Técnicos Destacados
* **Clases Base Abstractas (módulo `abc`):** Garantiza contratos e interfaces estrictas entre entidades.
* **Métodos Polimórficos:** Estandarización de cálculos para distintos tipos de evaluación.
* **Encapsulamiento Robusto:** Atributos privados con acceso protegido mediante propiedades y validaciones.
